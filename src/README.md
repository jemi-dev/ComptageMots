# ComptageMots

## Description
Programme Java qui compte le nombre total de mots dans un fichier texte.

## Structure du projet
- 'Main.java' : Classe principale contenant la logique du programme
- 'texte.txt' : Fichier texte utilisé pour les tests

## Fonctionnalités
- Lire un fichier texte volumineux ligne par ligne
- Séparer chaque ligne par les espaces
- Compter le nombre de mots par ligne
- Afficher le nombre total de mots du fichier

## Comment exécuter
1. Cloner le dépôt
2. Ouvrir le projet dans IntelliJ IDEA
3. Placer votre fichier texte à la racine du projet et le nommer `texte.txt`
4. Exécuter la classe `Main.java`
